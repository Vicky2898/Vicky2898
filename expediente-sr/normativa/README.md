# Normativa de referencia

Esta carpeta guarda, dentro del repositorio, el texto de la normativa que usa la herramienta, para que no se pierda cuando se reinicia la sesión de trabajo.

El repositorio es público. Por eso aquí solo se guarda:

- **Normativa ecuatoriana** (texto completo, es de acceso público): Reglamento de Seguridad Radiológica (D.S. 3640) y Norma Técnica MERNNR-MERNNR-2022-0011-AM, más memorandos y oficios de la Autoridad Reguladora sin datos personales.
- **Documentos internacionales con derechos de autor** (NCRP 147, IAEA-TECDOC-1958, ARCAL XLIX, GSR Part 3): solo notas con las tablas, ecuaciones y numerales que usa la herramienta, con la cita de la fuente. No se guarda el texto completo.

| `norma-tecnica-2022-0011.txt` | Norma Técnica MERNNR-MERNNR-2022-0011-AM (R.O. Cuarto Suplemento N.º 11, 25-feb-2022), texto extraído del PDF del Registro Oficial | Incluido |
| `reglamento-3640.txt` | Reglamento de Seguridad Radiológica, D.S. 3640 (R.O. 891, 8-ago-1979) | Incluido |
